# Hangline 使用指南

> 每截一张图，它就挂到屏幕顶上的一根绳上。指针停在屏幕顶边，绳子滑下来；移开，它收起。

移植自 macOS 应用 Tendedero。免安装：整个文件夹拷到任何一台 Windows 10 / 11，双击
`Hangline.exe` 就能用，不需要装 .NET 运行库，不需要管理员权限。

---

## 1. 第一次启动

双击 `publish\Hangline\Hangline.exe`。

没有窗口弹出来——这是对的。它是个常驻程序，出现在**右下角托盘**里：一枚灰色衣夹。
被折叠起来的话，点托盘左侧的 `^` 把它拖出来。

**已经有一个在跑，再双击一次 exe**：不会开出第二个，也不会什么都没发生——正在跑的那个
会把绳子放下来，当作"我在这儿"的回应（日志里写 `asked it to show the line`）。

建议第一件事：右键托盘图标 → **登录时启动** 打上勾。

想立刻看到绳子，右键托盘图标 → **把绳子放下来**。绳上没图时会有一句提示
"截一张图，它就挂在这儿"。

退出：右键托盘图标 → **退出**。

## 2. 日常怎么用

### 让图挂上绳

四种来源都会自动挂，你不需要做任何设置：

| 你怎么截 | 会发生什么 |
|:--|:--|
| `Ctrl+Alt+Shift+A` | 拖一个选框 → 松手即挂上，图从你框住的位置**飞进**绳上格子 |
| `Ctrl+Alt+Shift+F` | 全屏截图，直接挂上 |
| `Ctrl+Alt+Shift+W` | 只截当前活动窗口（不含标题栏外的隐形边框） |
| 微信 `Alt+A`、QQ `Ctrl+Alt+A`、`Win+Shift+S` 等任何工具 | 两条路都会挂上：**剪贴板**（这些截图一定会往剪贴板放一份，勾上"挂上复制的图片"即刻挂）＋**落盘目录**（文件进了被监听的文件夹就挂） |

被监听的目录：Hangline 自己的收件夹、`图片\Screenshots`、`图片`、`视频\Captures`、桌面。
数量有上限，超出时最老的一张会**掉落**（自己收件夹里的会进回收站，别处的只是从绳上取下）。

### 让绳子下来

把指针移到**屏幕最上边缘**，停住约 0.25 秒——绳子会弹簧式滑下来。
快速划过不会触发，必须"停留"。指针离开 0.5 秒后自动收起。
在顶边**点一下**（关掉那儿的某个菜单、点窗口的 ✕）会把绳子收回去，并且在你把指针
移开之前不再下来——否则点完菜单它又掉下来，没完没了。

另外两种：快捷键手动切换（出厂默认 `Ctrl+Alt+T`，**但它常被别的程序占用**，注册失败时日志会写 `hotkey ... refused (win32 1409...)`——在 设置 → 快捷键 里换一组，当前用的是哪个也写在那一行上）；刚挂上新图时它自己会下来 2.5 秒给你看。

### 对一张图能做什么

| 动作 | 结果 |
|:--|:--|
| 单击 | 复制。同时给图片和文件两种形式，粘到微信是图、粘到资源管理器是文件。卡片下方出现"已复制" |
| 双击 | 用系统默认程序打开 |
| 长按 0.45 秒 | 进标注编辑器（见下） |
| 中键点击 | 快速查看：原图铺满屏幕，`←` `→` 在绳上的图之间走，`Esc` 放回 |
| 右键 | 菜单：复制 / 打开 / 快速查看 / 标记 / 在文件夹中显示 / 存到桌面 / 取下或丢弃 / 取下左边全部 / 取下右边全部 |
| 按住拖动 | 拖到**别的程序**＝送一份副本，原图仍挂在绳上；拖到**文件夹**＝移动过去，卡片取下；拖到**回收站**＝删除 |
| 滚轮 | 图多时横向平移。绳上超过一屏能放下的数量时（见"绳上保留"），**卡片之间的缝隙**也接收滚轮，不然你得瞄着某张图才能滚 |
| 悬停 | 卡片放大到 1.035、阴影加深，左上角**淡入弹出**那个丢弃记号（260ms，从 0.6 倍弹到 1 倍）；移开就淡回去 |
| 点左上角的小圆标 | 丢弃（见下节，两种图标含义不同） |

### 卡片上的记号

- **左上角 ✕**：这张图在 Hangline 自己的收件夹里，点它＝送进回收站。
- **左上角 划掉的眼睛**：这张图在别处（桌面、你的图片文件夹），点它＝只是从绳上取下，**文件不动**。
  这个区别是故意的：Hangline 不会删你放在别处的东西。
- **中间的 ▶**：这是一段录屏，不是图片。
- 每张图挂上时都有一个**随机的小歪角**（±2.5°），每 7–16 秒来一阵"风"让它们轻轻晃——
  这是为了让它像个物件而不是个控件。托盘菜单的 **音效** 可以关掉声音。

## 3. 标注编辑器（长按打开）

深色全屏，中间是图，底部工具条：

| 工具 | 用法 |
|:--|:--|
| 矩形 / 箭头 / 画笔 | 按住拖 |
| 文字 | 点一下位置，打字，`Enter` 确认 |
| 马赛克 | 按住拖过要打码的区域 |
| 四个圆点 | 换颜色（红/黄/绿/蓝） |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（一次拖拽算一步） |
| `Enter` 或 保存 | **覆盖原文件**，按原图像素尺寸写回，绳上那张卡原地换图（不重新挂、位置不变） |
| `Esc` 或 取消 | 放弃，文件不动 |

## 4. 录屏

`视频\Captures` 里的录屏会自动挂上，带 ▶ 徽标。**长按**它进剪辑窗口：

- 打开即自动播放；
- 拖"起""止"两根滑杆选保留区间；
- `Enter` 保存——用流拷贝（不重编码），672MB 的录屏裁一段只要不到一秒。

剪辑依赖电脑上已有的 **ffmpeg**。Hangline 不捆绑也不下载它；探测不到时，剪辑窗口会
明说"这台电脑上没有 ffmpeg，剪不了这段"，并把按钮变成「打开」交给系统播放器——
不会假装保存成功。

## 5. 托盘菜单逐项说明

菜单里**带 ✓ 的项就是开关**：勾着＝开着。整张表每次右键都按当前真实状态重画，
所以"绳子放下"的勾会跟着你自己悬停放绳的动作变，不是点了才算。

| 项 | 作用 |
|:--|:--|
| 绳子放下 | 一个开关：勾着＝绳子正放着，点一下收起来、再点一下放下来。等同于快捷键 |
| 全部取下 | 先把绳子放下来，再让每张图按自己 ✕ 的含义依次掉落（收件夹内的进回收站，别处的只是取下）——过程看得见，不是瞬间消失 |
| 接管截图 | 开＝Hangline 把系统截图这件事接过来：**① `PrtSc` 键被注册成"拖框截图"**（按下后整屏**冻住并变暗**，拖出方框就截，截完直接挂上绳），**②** 监听 `图片\Screenshots`、桌面、`视频\Captures`。关＝只挂 Hangline 自己截的图和你手动添加的文件夹，不去读你的目录；`PrtSc` 交还给系统。实测关掉后监听目录从 5 个变 1 个。若 `PrtSc` 已被别的程序（OneDrive、截图工具、键盘驱动）抢注，日志会写 `Print Screen is held by another app`，其余功能不受影响 |
| 挂上复制的图片 | 复制到的图片也挂上绳。开启时托盘图标里的衣夹会被填满。**微信 / QQ 截图截完一定有一份在剪贴板里**，所以这一条开着它们就是"截完立刻挂上"。两种复制都接：剪贴板里是**图片本身**（截图工具、浏览器里的图）→ 存成 png 再挂；在资源管理器里**复制了一个图片文件** → 直接把那个文件挂上，不再另存副本（同一次复制带进来的缩略图会被忽略）。纯文字不挂（密码管理器放的东西不会变成文件）。bitmap 上限 64MB / 8000 万像素 |
| 什么时候放绳 | 三个**互相独立**的开关：指针停在顶边 / 有新图挂上时 / 盖住全屏应用。可以同时勾着，不是三选一 |
| 另外监听这些文件夹 | 最多 3 个；点名字在资源管理器里打开它，「停止监听」子菜单里可以逐个取消（满了 3 个时"添加文件夹"就不再出现，而不是灰着） |
| 绳上保留 | 放得下多少算多少（默认，随屏幕宽度 3–12 张）或固定 25 / 50 / 100 张（超出用滚轮平移着看） |
| 尺寸 | 小 / 中 / 大——只改照片和占位，夹子、绳子、玻璃框不变 |
| 快捷键 | 显示当前"放绳/收绳"的键，并可改。四个键（放绳、区域、全屏、窗口）都在设置窗口的快捷键页里改 |
| 打开截图文件夹 | 打开 Hangline 的收件夹 |
| 音效 / 登录时启动 | 见上。音效**当场生效**，不用重启 |
| 设置… | 打开设置窗口（下一节） |
| 退出 | 释放热键与剪贴板监听后退出 |

### 设置窗口（托盘 → 设置…）

托盘菜单的放大版，两页，**改完立即生效并写盘**，没有"保存/取消"：

- **常规**：绳子放下、全部取下、接管截图、挂上复制的图片、什么时候放绳（三个独立
  勾）、绳上保留、尺寸、音效、登录时启动、打开截图文件夹。
- **快捷键**：放绳/收绳 + 区域截图 + 全屏截图 + 当前窗口，每行显示当前键，可以
  「更改…」（弹录制框，按一组新键即生效，按 `Esc` 放弃）或「恢复默认」。
  下面单独一栏说 `PrtSc`：它不是"能改的键"，而是接管截图开没开，所以这里
  **如实显示三态**——已接管 / 被别的程序占着 / 已交还给系统。

窗口和托盘读的是同一份设置，谁改了另一边下次打开就是新的。

## 6. 文件都在哪

| | |
|:--|:--|
| 自己截的图 | `%APPDATA%\Hangline\Screenshots`，命名 `截屏 2026-10-12 下午3.45.06.png`（重名自动加 ` 2`） |
| 复制来的图 | 同一目录，`剪贴板 2026-10-12 下午3.45.06.png`，权限只给你的账户 |
| 设置 | `%APPDATA%\Hangline\settings.json`（原子写入，改坏了会回落默认而不是启动失败） |
| 日志 | `%APPDATA%\Hangline\hangline.log`（超过 300KB 自动截断） |

有几项和 Mac 原版一样只存在设置文件里、不进托盘菜单，改完重启生效：

| 键 | 默认 | 作用 |
|:--|:--|:--|
| `quietHang` | `false` | 挂上新图时不出声（掉落时仍然有声） |
| `watchPicturesFolder` | `true` | 接管截图开着时，是否连 `图片` 根目录一起读 |
| `watchDesktop` | `true` | 是否读桌面（系统截图默认不落桌面，关掉可让 Hangline 完全不碰桌面） |
| `watchCaptures` | `true` | 是否读 `视频\Captures`（系统录屏的落点） |
| `language` | `"auto"` | `auto` 跟随 Windows 显示语言；`zh-Hans` / `en` 强制一种 |
| `pegged` | `[]` | 上次退出时绳上还有哪些图。原版重启后绳子是空的，这里会原样挂回来 |


**绳只是这些文件的一个视图，文件本身从不被程序移动。** 你在资源管理器里删掉一张挂着的
图，卡片会自己掉落；把它移走，也一样。

## 7. 常见问题

**复制了图片但没挂上？** 日志会告诉你它看到了什么：`clipboard: files=False text=True image=True`
就是"收到、有图、准备挂"；`files=True` 时紧跟一行 `clipboard: hung 2 copied files`——数字是
这次复制里图片文件的个数，复制的是文档或压缩包时它是 0，那是故意的；`image=False` 是剪贴板里
只有文字。如果连 `clipboard:` 这一行都没有，说明"挂上复制的图片"
没勾上，或者复制那个动作发生在另一个桌面会话里。

**截了图没挂上？** 先看托盘图标在不在（程序是否活着），再看日志
`%APPDATA%\Hangline\hangline.log`。用 `Win+Shift+S` 截的图要落进
`图片\Screenshots` 才会被挂上——那需要系统里开着"自动保存截图"；否则它只在剪贴板里，
这时打开"挂上复制的图片"就能挂上。

**快捷键没反应？** 三种可能，日志分得很清楚：
`refused (win32 1409...)` = 这个键被别的程序占了（`Ctrl+Alt+T` 就是常见被占的一组，
所以出厂默认虽然写着它，你的机器上可能注册不上）；`is already Hangline's "region" key`
= 它被我们自己另一个功能占着，去 设置 → 快捷键 给那一个换一组；
`hotkey id=N fired` = 键是好的，功能在跑，那就不是快捷键的问题。
自建截图的三个键默认带 Shift，就是因为 `Ctrl+Alt+A` 已经被 QQ / 微信截图占用。

**按 `PrtSc` 还是弹出系统截图工具？** 打开"接管截图"时 Hangline 会注册 `PrtSc` 这个键，
注册成功就不会再轮到系统工具；如果别的程序（OneDrive、键盘驱动）先抢到了，日志会写
`Print Screen is held by another app`。想彻底还给系统：在 Windows 的
设置 → 辅助功能 → 键盘 里关掉"使用打印屏幕键打开屏幕截图"，或者取消勾选"接管截图"。

**绳子会不会挡住我点上面的窗口？** 不会。绳子的窗口默认对鼠标完全穿透，
只有**照片本身**那一小块会接收点击；绳子收起后窗口直接不存在。

**全屏玩游戏/放幻灯片时它会不会跳出来？** 不会，除非你在"什么时候放绳"里勾了
"盖住全屏应用"。

**它联网吗？** 不。没有账号、没有统计、没有任何网络请求。

**怎么卸载？** 托盘 → 退出，然后删掉整个文件夹。再顺手在托盘菜单里把"登录时启动"
关掉（或直接删 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 里的 `Hangline`）。
`%APPDATA%\Hangline` 里的图和设置要不要留，你自己决定。

## 8. 与 Mac 原版的差异

玻璃材质没有真背景模糊（Windows 无受支持的跨进程模糊 API）、无法接管系统截图设置
（改成自建截图 + 监听）、录屏剪辑依赖机器上已有的 ffmpeg（系统的 `VideoEditingService`
从 .NET 8 够不到，实测过）、标注编辑器是自己写的（系统「标记」在 Windows 没有对应物）。

逐条写清楚在 [parity.md](parity.md)。

## 9. 给开发者

```powershell
scripts/dev.ps1              # 编译并启动真正的 exe
scripts/dev.ps1 -Extra "--pin"   # 让绳子常驻，方便看
scripts/stop.ps1             # 停掉所有实例（含 dotnet 宿主起的）
scripts/publish.ps1          # 便携目录；-SingleFile 出单文件变体
dotnet test                  # 118 个单元测试
```

必须用 `Hangline.exe` 启动，不要用 `dotnet Hangline.dll`：进程的 DPI 感知度取自 exe 的
manifest，走 dotnet 宿主时监视器尺寸会被系统按缩放比例虚拟化，量出来全是错的。

开发期开关：`--pin`（强制放绳）、`--hang 路径[@x,y,w,h]`（挂一张图，带起飞矩形就会飞）、
`--take-down 秒`（N 秒后触发"全部取下"，好在不碰鼠标的前提下抓到先放绳再逐张掉的顺序）、
`--settings [页]`（直接打开设置窗口的某一页）、`--size`、`--preview`、`--annotate 路径`、
`--annotate-test 路径`、`--trim-window 路径`、`--cursor x,y`（**会抢走你的鼠标**）。
环境变量：`HANGLINE_SLOWMO=6` 把动画放慢好抓帧，`HANGLINE_HIT=1` 每 2 秒记录一次穿透判定，
`HANGLINE_LAYOUT=1` 记录首张卡片的几何。

配套的自检脚本：`scripts/shot.ps1`（抓屏，可裁区域）、`scripts/winrect.ps1`（读绳子窗口的
可见性与矩形，用来判断放绳/收起/穿透，不用靠肉眼看截图）、`scripts/mouse.ps1`（移动/点击
真实光标）。三个脚本都会先给自己声明 PerMonitorV2——一个 DPI 无关的探针读到的是被虚拟化
的坐标，会把放对的窗口读成错的。
