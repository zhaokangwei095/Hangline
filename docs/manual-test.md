# 人工验收清单

自动测试覆盖的是纯逻辑（118 个）；下面这些必须有眼睛看、有手点。
每项都写了"应该看到什么"，不符合就是 bug。

## A. 手感

| 步骤 | 应该看到 |
|:--|:--|
| 指针移到屏幕最上边，停住 | 约 0.25 秒后绳子带着照片**弹簧式**滑下，末尾有极轻微的回弹 |
| 只是快速划过顶边 | 绳子**不**放下来（要"停留"，不是"经过"） |
| 指针离开绳子区域 | 停留 0.5 秒后上收，收是 `easeIn` 0.22 秒，比放下来干脆 |
| 什么都不做，盯着绳子 | 每 7–16 秒来一阵风，每张图**延迟不同、幅度不同**地轻摆 |
| 绳上没图且你没碰它 | 0.7 秒后自动收起 |
| 截一张图 | 绳子自己下来 peek 2.5 秒，"叮"一声 |

## B. 鼠标穿透（这条最容易做错）

1. 把记事本窗口最大化，让光标能点到绳子所在的顶部区域。
2. 绳子收起时：在顶部任意位置点击、拖选文字、滚滚轮 → 全部应当作用在记事本上。
3. 绳子放下时：在**绳子与卡片之间的空白**点击 → 仍然穿透到记事本。
4. 在**照片上**点击 → 不穿透，是复制。

第 3 条失败的表现是：绳子放下来以后，屏幕顶部一条都点不动了。

例外：托盘「绳上保留」设成 25/50/100 且**图多到一屏放不下**时，照片所在的那一条
水平区间（从最高的夹子到最低的卡片底，横穿整条绳）会接收指针，这样滚轮不用瞄准
卡片——这时第 3 条的点击落在绳子上是预期行为，原版也这样。想验证第 3 条，先把
「绳上保留」改回"放得下多少算多少"。

## C. 交互矩阵

对"自己收件夹里的图"和"桌面/图片文件夹里的图"各做一遍（✕ 的行为不同）：

| 动作 | 图片 | 录屏 mp4 |
|:--|:--|:--|
| 单击 | 复制，卡片下方出现"已复制"，卡片轻晃 3° | 复制文件 |
| 双击 | 系统默认程序打开 | 播放器打开 |
| 长按 0.45 秒 | 进**内置标注编辑器**，`Enter` 保存后卡片原地换图、不重新挂；`Esc` 放弃则文件不动 | 打开 |
| 右键 | 菜单：复制 / 打开 / 快速查看 / 标记 / 在文件夹中显示 /（收件夹内）存到桌面 / 取下或丢弃 / 取下左侧全部 / 取下右侧全部 | 同左 |
| 悬停 | 放大到 1.035、阴影变深、左上角出现 ✕（收件夹内是 ✕，别处是划掉的眼睛） | 中间有播放徽标 |
| 拖到资源管理器文件夹 | 文件被**移动**，卡片掉落 | 同左 |
| 拖到桌面 | 复制到桌面，卡片**留下** | 同左 |
| 拖到回收站 | 进回收站，卡片掉落 | 同左 |
| 拖到微信/Paint | 送一份副本，卡片留下 | 同左 |
| 拖出去后取消 | 卡片飞回原位 | 同左 |
| 滚轮 | 图多时横向平移 | 同左 |

## D. 监听

- `Win+Shift+S` 截一块（系统会存到 `图片\Screenshots`）→ 挂上。
- `Ctrl+Alt+Shift+A` 自建截图 → 选框 → 挂上，且**桌面上不留文件**。
- 复制一张网页图片（托盘里打开"挂上复制的图片"）→ 挂上；关掉后不再挂。
- 复制一段纯文字 → **不**挂。
- 往监听文件夹一次拷 20 张 → 全部挂上，最老的按容量规则掉落，不卡死。
- 在资源管理器里删掉一张挂着的图 → 卡片自己掉落。

## E. 全屏与多屏

- 游戏独占全屏 / 浏览器全屏视频 / PPT 放映 → 绳子不放下来。
- 托盘「什么时候放绳 → 盖住全屏应用」打开后 → 照常放下来。
- 双屏：把指针移到另一块屏的顶边 → 绳子整体搬到那块屏，宽度精确贴边、无缝。
- 两块屏缩放比例不同（如 100% + 150%）→ 卡片不糊、不溢出、不缺一像素。

## F. 系统集成

- `Ctrl+Alt+T` 全局切换；被别的程序占用时日志有记录且旧键仍可用。
- 托盘每一项都能点，勾选状态与实际行为一致。
- 「登录时启动」开关后重启电脑 → 绳子还在。
- 退出后：无残留进程、热键释放、托盘图标消失。

## G. 数据

- `%APPDATA%\Hangline\settings.json` 手改成非法值（`"lineSize": "gigantic"`）→ 下次启动回落默认，不崩。
- 挂几张图 → 退出 → 重开：原样重挂，且不会因为容量规则在启动时掉图。
- 挂机 4 小时：内存不持续上涨（每张卡片持有一张缩略图，数量有上限）。

## H. 交付

- 把 `publish\Hangline\` 整个拷到一台没装 .NET 的机器 → 双击可用。
- Windows 10 2004+ 与 Windows 11 各跑一遍。
